# Spec — `eu_and_v3.ipynb` (single-switch and AND reports from sampled stem opening)

> Current as of 2026-10-11. The code is the source of truth: if this file and the notebook or
> the helper modules disagree, the code wins and this file is wrong. Cells are referred to by
> their section heading, not by index.

(`eu_and_v3_report_<time>.{html,pdf}`), **part 2** the AND report
(`eu_and_v3_and_report_<time>.{html,pdf}`) from the top `AND_TOP_N` designs of part 1, plus CSV
exports and (optionally) the data for an interactive page. It replaces
the earlier `and_eu_report.ipynb`, which ranked by exact partition-function quantities (removed;
see git history).

## Hard rules

1. **Fold only through `FoldEngine`**, one instance built once (`fx.fold_engine(real=True,
   temperature=TEMPERATURE_C)`) and published with `use_fold_engine(folder)` before any pool
   starts (the pools fork). No `import RNA` in notebook or helper code.
2. **One process-pool call per batch**; fork context.
3. **Raw values only; `None` for a measurement that failed**, never `0.0`. Percentages that
   cannot be computed stay `None` and print `n/a`.
4. **Seeds are literals** (`SEED`, `CHECK_SEED_OFFSET`, `SPACER_SEED`); a rerun repeats.
5. **No draw is filtered or corrected.** The sampler is checked against the matrix per state;
   a state that fails is shown red, not repaired (a threshold on draw energy was tried and
   rejected as inconsistent).
6. **The notebooks are edited directly** (they are no longer generated by a script); keep the
   parameter cell as the one place of tunables.

## Definitions

### Stem and open nucleotides
A design has one hairpin; `stem_up` is its 5' side, `stem_down` the 3' side, both of length
`L`. In a structure `s` a `stem_up` nucleotide is **open** if it is not paired to any
`stem_down` nucleotide (it may be unpaired, or paired to the trigger or to anything else).
`k(s)` = number of open nucleotides; `r(s)` = longest run of consecutive open nucleotides
(`r <= k`). Positions are 0-indexed, start-inclusive, end-exclusive.

### Open (single)
`Open = E[r] = sum_s P(s) r(s)`, estimated as the mean of `r` over `N_SAMPLES` structures
drawn from the Boltzmann ensemble (`FoldEngine.sample_structures`). No normalisation is
needed: draws are already distributed as `P(s)`. Reported in nt and as `100 Open / L`.

### Single report
`ON = 100 Open(switch + trigger) / L`.
`OFF = max(100 Open(switch alone) / L, Control)` — the worst of the alone state and the
controls. `Control = 100 max_j E[k]_matrix(switch + mismatched trigger_j) / L`, over
`N_CONTROLS` mismatched triggers (real triggers of other designs sharing at most
`CONTROL_MAX_OVERLAP_NT` nt of identity with the true trigger, or `CONTROL_EXTRA_TRIGGERS`).
The matrix `E[k]` is an **upper bound** of Open, and it is used because the sampler is
unreliable for mismatched states (it is not sampled). `ON - OFF` (percentage points) ranks
the designs. Ratio `ON / max(OFF, OFF_FLOOR_PCT)` is information only (asterisk when
floored). `dG = G(switch+trigger) - G(switch) - G(trigger alone)` (ensemble free energies,
`FoldEngine.partition`), kcal/mol, concentration not included.

### AND report
Fusion: hairpin A = design A up to its own Kozak; hairpin B = design B after its own prefix;
optional spacer between (see below). Four states per candidate: alone, +A, +B, +A+B, plus
`N_CONTROLS` control states (two mismatched triggers in the +A+B layout).
`ON_min = 100 E[min(r_A / L_A, r_B / L_B)]_{+A+B}` — in each structure each hairpin's longest
open run as a fraction of its **own** stem, the smaller of the two, weighted by `P(s)`: both
hairpins open at once, each relative to its own length (`open_frac_sampled`). `OFF = 100
max(Open_alone, Open_+A, Open_+B, Control)` with the same `Open = E[min(r_A / L_A, r_B / L_B)]`
for the OFF states and `Control = max_j min(E[k_A] / L_A, E[k_B] / L_B)_matrix` (upper bound).
ON and OFF use one rule, so `ON_min - OFF` compares like with like. The earlier form
`100 E[min(r_A, r_B)] / min(L_A, L_B)` compared the runs in nucleotides: with stems of 21 and 12 nt,
"A open for 12 of 21, B fully open" scored 100%, the same as both fully open. Per-hairpin
normalisation scores it 57%; for equal stems the two forms are identical. `E[min(r_A, r_B)]` in
nt (`open_sampled`) is still sampled and used by the sampler check (below) and the nt columns. Candidates are ranked by
`ON_min - OFF` (joint). The sum-based `ON_sum = 100 E[r_A + r_B] / (L_A + L_B)` and
`ON_sum - OFF` are listed for information only (table, CSV and explorer rows); they would give
credit when only one hairpin opens (`ON_sum = 50`, `ON_min = 0`). The summary also counts the
listed candidates whose `ON_min` is below half of `ON_sum` (uneven response) and the rank
agreement between the two orders. `ratio = ON_min / max(OFF, OFF_FLOOR_PCT)` is information
only. The tied group, the noise and the verification all refer to `ON_min - OFF`.
`dG = G(+A+B) - min(G_alone + G_A + G_B, G_+A + G_B, G_+B + G_A)`.

### Trigger-pair screen
`trigger_pair_too_similar(A, B)` rejects a pair when either (a) the longest antiparallel
complementary run exceeds `FAKE_MAX_SEQ_OVERLAP_NT` or (b) the longest same-direction identical
run does. The complementary run tolerates G·U wobble: on every alignment (diagonal of `A`
against `B` reversed) each maximal stretch of pairing positions is searched for its longest
**sub-run** whose wobble share is at most `WOBBLE_MAX_FRACTION`, so a wobble-heavy end cannot hide
an acceptable stretch behind it (`GAUAUAUUUAC` / `GUGGGUGUGUU`: a 10-position run with 5 wobble
pairs is found at a cap of 0.5). Tested against an exhaustive search.

### Upstream AUG screen
`EXCLUDE_UPSTREAM_AUG = True` drops every construct whose fused RNA has an AUG that begins
before the start of the second hairpin's `stem_down` (`_switch_construct.upstream_augs`, built
on `engine.sequences.find_augs`): in hairpin A, the spacer, or hairpin B's toehold, stem_up or
loop. The intended start codon is the payload's, after hairpin B and its Kozak; an earlier AUG
is a competing start codon. An AUG beginning at or after the start of `stem_down_B` is not
counted. Spacer candidates containing `AUG` are removed from the pool first (so a spacer never
causes the exclusion; an AUG made at a junction still does). The count is reported next to the
other exclusions (self-pairs / too similar / upstream AUG / fuse failed). Part 1 (single
switches) is not screened. The toggle is for comparison: with it off the candidate set is the
one without this screen (the spacer pool is then also unfiltered). The screen looks only for the
AUG triplet in the fused sequence; it does not judge Kozak context, reading frame or whether the
AUG is accessible. In the run of 2026-10-11 (top 20 of 150 designs) the 800 pair variants (20 x 20
ordered pairs, with and without a spacer) lost 40 self-pairs and 80 too-similar pairs, and the
screen then removed 580 of the remaining 680 (85%), leaving 100 candidates.

### Spacer
`generate_spacer_candidates`: a fixed pool (`SPACER_CANDIDATE_POOL_SIZE`, seed `SPACER_SEED`)
of random sequences, lengths cycling `SPACER_MIN_LENGTH..SPACER_MAX_LENGTH`, A/U-biased (35%
each, 15% G and C). `pick_optimized_spacer` chooses per pair the candidate with the smallest
worst-case complementary run against the two toeholds and two triggers (ties: lower GC, then
pool order). Both variants (`no_spacer`, `spacer`) are run and ranked together.

### Pool of part 2
The top `AND_TOP_N` rows of part 1's ranking (tied group first, then `ON - OFF`), taken from
memory (`scored`). All ordered pairs, no self-pairs, no pair whose triggers share a run above
`FAKE_MAX_SEQ_OVERLAP_NT` (identity, or complementarity with at most `WOBBLE_MAX_FRACTION`
G·U wobble), and no construct with an AUG before the second hairpin's `stem_down` (see
"Upstream AUG screen"). Pairs are screened in that order and each exclusion is counted
(self-pairs / too similar / upstream AUG / fuse failed). `single_rank` in part 2 = rank in part 1.

## Sampling and verification

- **Strand order matters** for `sample_structures` (ViennaRNA's sampler is miscalibrated for
  some multi-strand complexes depending on which strand is written first).
  `FoldEngine.sample_structures(strands, n, seed, first_strand)` rotates the strands so that
  `first_strand` is written first and maps the structures back. Measured rule: put the
  trigger on the side of the switch nearest its target hairpin. Single: trigger first (the
  default, last strand first). AND: tA first for +A, fused first for +B, tA first for +A+B
  (written fused & tB & tA, see `both_triggers_extra`: `fused & tA & tB` is a pseudoknot).
- **Same model as every other fold.** `sample_structures` builds its compound with
  `configured_compound(..., uniq_ml=1)`, so `no_gu`, dangles, energy tables, temperature and
  the parameter lock match `mfe`, `partition` and `base_pair_probabilities`; `uniq_ML = 1`
  (required for stochastic backtracking) is the only override and is recorded in
  `FoldEngine.provenance()` as `sampling_model_override`. Seeding and drawing run under one
  lock because ViennaRNA's generator is process-global.
- **Check per state:** the sampled `E[k]` must equal the matrix `E[k]` within
  `tau = VERIFY_SIGMA * sd(k) / sqrt(N) + VERIFY_FLOOR_NT` (per hairpin for AND; `sd(k)` from
  that state's own draws), and `Open <= E[k]_matrix + tau` (sanity bound). The floor exists
  because a nearly closed state can have `sd = 0` from 2000 draws. A *measured* `sd = 0` is a
  real value and is used as is (tolerance = the floor); only a missing `sd` (None/NaN) falls
  back to `L/2`, which would make the check nearly vacuous (`_report_stats.py`). Green/red only shades the
  `E[k]` cells (Appendix A for AND); it never changes a value.
- The matrix gives `E[k]` exactly (`sum_i (1 - sum_j p_ij)`), not runs, joint events or
  `P(k >= m)`. For +A+B it bounds the sum `E[r_A + r_B] <= E[k_A] + E[k_B]`.
- **Noise:** the second run (`SEED + CHECK_SEED_OFFSET`) gives the seed-to-seed change of
  `ON - OFF` (AND: `ON_min - OFF`); median and 95th percentile are reported.
- **Tied group:** designs within the 95th percentile of the best `ON - OFF` (AND: `ON_min - OFF`) form one group
  (marked †), listed first and ordered by `dG` (more negative first); the rest follow by
  `ON - OFF`. Only sampling noise is counted. A more stable hairpin makes `dG` less negative,
  so this ordering slightly favours less stable switches (stated in the reports).

## Pipeline (by section)

Setup → Parameters → **Part 1**: load designs and sample both states (twice) → Open, checks
and ranking (controls, `dG`, noise, tied group) → correlation with the CSV rank (saved as a
separate PNG only) → details per listed design (parts table, 2D structures of alone and
+trigger, heat maps) → report (HTML with Details buttons; PDF from the print variant with a
details appendix; CSV of all designs) → **Part 2**: pool → fuse candidates and sample the
four states twice (+ control matrices) → ranking, tied group, `dG`, noise → details per listed
candidate → report (landscape PDF; Appendix A with the `E[k]` columns and the verification) →
export rows and detail panels for an interactive page → plot of the trigger positions of the
listed candidates (PNG, outside the report).

Part 2 names that would clash with part 1 end in `_and` (the two parts share one kernel).

## Empty and small results

All pairs excluded is a valid outcome: part 2 then writes the report with a "No eligible AND
candidates" paragraph and the exclusion counts, a CSV with only its header, an empty `rows.json`
and no trigger-position plot; the medians, the noise estimate and the rank correlation are
`n/a` (`_report_stats.median_text`, `noise_summary`, `spearman`, `num_text`), never 0. A single
candidate has no rank correlation (undefined) and forms its own tied group. `AND_MAX_CANDIDATES`
makes such cases reproducible in a test.

## Provenance in the reports

Both reports list at the top of their parameter table: the git commit of the code that rendered
the report (with "+ uncommitted changes" if tracked files differ), the input CSV name, SHA-256
and size, and the folding model (ViennaRNA version, energy table and its SHA-256, temperature,
dangles, special hairpins, no lonely pairs, no G·U, no G·U closure; sampling adds `uniq_ML = 1`
only), plus the saved results files when sampling was not repeated
(`_report_stats.run_provenance`). The commit is that of the renderer: with `RESULTS_TO_LOAD*` the
sampled values were produced by whichever revision wrote those files.

## Limitations (stated in the reports)

Structure-based equilibrium prediction only (no kinetics, concentration, translation or
start-codon accessibility, no experimental calibration); the +A+B ensemble assumes the
complex formed; trigger accessibility/self-structure and cross-talk are not assessed; `dG`
omits concentration; the sampler fails for some states (shown red, kept in medians); controls
are one matrix upper bound per mismatched trigger; OFF mixes a sampled alone value with
matrix bounds for the controls, so the control often sets OFF (stricter ranking); tie
threshold counts Monte-Carlo noise only; a design may have fewer than `N_CONTROLS` controls
or none (no other design's trigger is dissimilar enough): the reports then show `n/a` for the
control statistics, count the designs with full / fewer / no controls, and OFF falls back to
the other states; percentages are not fully neutral to stem length; the upstream-AUG screen is
a plain triplet search and part 1 is not screened; a screen that removes most pairs (85% of those
reaching it in the last run) leaves a small candidate pool, so `AND_TOP_N` bounds what part 2 can find.

## Traps (real mistakes already made here)

1. **Sampler strand order.** Writing the strands in the wrong order gave stem-open draws with
   energy far above the ensemble's. Use the order rule above and verify against the matrix.
2. **Sampled controls.** The sampler is unreliable for mismatched triggers regardless of
   order; use the matrix upper bound.
3. **`uniq_ML=1` is required** for `pbacktrack` sampling (set inside `sample_structures`).
4. **Raw LaTeX in HTML templates.** Templates are raw strings: write `\(` once. A doubled
   backslash shows the formula source in the PDF. Check the PDF text for `\(`.
5. **Floor on tolerance.** Without `VERIFY_FLOOR_NT`, states with `sd = 0` turn red because
   of draws that missed a rare opening.
6. **Clipped tables.** A wide table loses its last columns in the PDF; fonts and padding of
   the tables were tuned per report; re-check the rendered page after adding columns.
7. **Name clashes after the merge.** Part 2 reuses names from part 1; when adding code to
   part 2 use the `_and` names, and do not reassign `scored`, `designs` or `folder`.
8. **Counts as percentages.** A count of open nucleotides favours long stems for ON; percentages
   of the stem are used. OFF does not become neutral either.
9. **Mixed rank systems.** The "single rank" shown in part 2 is the rank in part 1 (tied
   group first); never recompute it from `ON - OFF` alone.
10. **Traps inherited from the earlier AND report still apply to `_joint_state_parallel.py`**:
    select fakes by sequence, not transcript position; accept G·U wobbles in complementarity
    screens; never `try/except: return 0.0` around a fold; do not read joint events from
    marginals (use `constrained_probability`).

11. **A measured zero is not a missing value.** `state.get("k_a_sd") or l_a / 2` treated a real
    `sd = 0` as missing and widened the tolerance from 0.02 nt to over 0.5 nt, so a sampled mean
    of 0 verified against a matrix mean of 0.3. Test `is None`, never truthiness.
12. **Complement the pair test, not the partner.** The wobble helper reverse-complemented B and
    then tested complementarity again, so A×12 vs U×12 scored 0. Reverse B only.
13. **An empty control pool is a normal outcome**, not an error and not a zero.
14. **An upstream-AUG count is not a quality score.** A construct with an AUG before the second
    `stem_down` is removed before any folding; it never appears in the CSV with a flag. To see
    what the screen removed, run with `EXCLUDE_UPSTREAM_AUG = False`.
15. **Results saved before a definition change cannot be re-rendered.** `RESULTS_TO_LOAD_AND`
    refuses files without `open_frac_sampled`; sample again instead of defaulting the field.
16. **A wobble-heavy end hides a valid sub-run.** Taking only the whole stretch that meets the
    wobble cap missed `GAUAUAUUUAC` / `GUGGGUGUGUU` (returned 6, truth 10). Search sub-runs on
    every diagonal.
17. **Zero or one survivor of the screens.** Indexing `scored_and[0]`, taking a median of an empty
    list or a rank correlation of one point fails; use the `_report_stats` helpers and test the
    empty and singleton workflows.
