# Historical and superseded material

These documents preserve unique rationale, scientific observations and provenance. They are
**not current installation instructions, capability claims or release approval**. Begin with
[the current documentation index](../README.md) and [pinned status](../status.md).

- `records/`: former entry points, historical roadmap, dated audits, old wiki draft and first smoke-run narrative
- Scientific/operator design subdirectories: original long-form designs retained when active guides were rewritten
- [Design reference](../design-reference/): original UI artifacts, not a current specification
- [Historical technical figures](../figures/README.md): diagrams from the older wiki snapshot

Originals are preserved byte-for-byte where copied. Relative links inside archived originals
retain their original context; use the source inventory's immutable baseline links when a
historical link no longer resolves from its relocated directory. This deliberately avoids
rewriting scientific records under a new date. Active guides use checked current links.

[The source inventory](../evidence/documentation-inventory.md) maps every baseline Markdown
source and supporting documentation artifact, with original checksums and preservation paths.
[The full baseline manifest](../evidence/baseline-file-manifest.json) accounts for all tracked
files. Datasets, notebooks, figures, test fixtures and vendor evidence are not deleted or rewritten
by this documentation reorganization.

The [post-merge main snapshots](post-merge-main-2026-10-16/INDEX.md) preserve all five
files reconciled across documentation conflicts, including the PR82 research roadmap.
